# tokens-por-uso

Catálogo de plugins de Claude Code con un mod: **tokens-por-modelo**. Cuenta los tokens de entrada, salida, lectura de caché y escritura de caché de cada modelo (subagentes incluidos), con un panel `/tokens` y una línea encima del prompt. Los datos se guardan solo en memoria.

## Instalar

En la app de escritorio: **+** junto al cuadro del prompt → **Plugins** → **Add marketplace** con `alejandroRuedaGallego/tokens-por-uso` → **Add plugin** en tokens-por-modelo.

En la terminal:

```
/plugin install tokens-por-modelo --marketplace alejandroRuedaGallego/tokens-por-uso
```
